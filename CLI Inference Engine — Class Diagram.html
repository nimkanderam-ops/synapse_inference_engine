CLI Model-Inference Engine — Class Diagram

Final revision · C++ OOP mini-project

classDiagram
    class CLIApp {
        -CommandParser parser
        -ModelManager modelManager
        -Tokenizer tokenizer
        -InferenceEngine engine
        -OutputGenerator outputGen
        +run() void
        +readInput() string
        +dispatch(unique_ptr~Command~ cmd) void
    }
    class AppContext {
        <<struct>>
        +ModelManager& modelManager
        +Tokenizer& tokenizer
        +InferenceEngine& engine
        +OutputGenerator& outputGen
    }
    class CommandParser {
        -AppContext& ctx
        +parse(string input) unique_ptr~Command~
    }
    class Command {
        <<abstract>>
        +execute() void
    }
    class LoadModelCommand {
        -string modelPath
        -AppContext& ctx
        +LoadModelCommand(string path, AppContext& ctx)
        +execute() void
    }
    class PromptCommand {
        -string promptText
        -AppContext& ctx
        +PromptCommand(string prompt, AppContext& ctx)
        +execute() void
    }
    class ModelManager {
        -unique_ptr~Model~ model
        +loadModel(string path) void
        +destroyModel() void
        +getModel() Model&
        +hasModel() bool
    }
    class ModelFactory {
        +createModel(string path) unique_ptr~Model~
    }
    class Model {
        <<abstract>>
        #vector~LayerPtr~ layers
        +forward(const Tensor& input) Tensor
    }
    class ToyTransformerModel {
        +forward(const Tensor& input) Tensor
    }
    class Layer {
        <<abstract>>
        +forward(const Tensor& input) Tensor
    }
    class DenseLayer {
        -Tensor weights
        -Tensor bias
        +forward(const Tensor& input) Tensor
    }
    class Tokenizer {
        -map~string,int~ vocab
        +encode(string text) Tensor
        +decode(const Tensor& tokens) string
    }
    class InferenceEngine {
        +run(const Model& model, const Tensor& input) Tensor
    }
    class Tensor {
        -vector~float~ data
        -vector~int~ shape
        +add(const Tensor& other) Tensor
        +matmul(const Tensor& other) Tensor
    }
    class OutputGenerator {
        -Tokenizer* tokenizer
        +generate(const Tensor& output) string
    }

Reading the arrows

▷ hollow triangle — inheritance ("is-a")
◆ filled diamond — composition, owned via unique_ptr
→ solid arrow — association, a stored reference/pointer member
⇢ dashed arrow — dependency, used only as a parameter or return value

What each class is responsible for

ClassAreaTask
CLIAppOrchestrationRuns the REPL loop, reads input, builds and dispatches commands
AppContextOrchestrationRead-only bundle of references so a command can reach the subsystems it needs
CommandParserOrchestrationTurns raw text into the right concrete Command, injecting AppContext
CommandOrchestrationAbstract; declares execute()
LoadModelCommandOrchestrationTells ModelManager to swap models
PromptCommandOrchestrationTokenizes, runs inference, prints the result
ModelManagerModelOwns the model's lifetime via unique_ptr; delegates construction to ModelFactory
ModelFactoryModelOnly class that knows concrete Model subclasses; builds the right one from a path
ModelModelAbstract; owns the layer stack, defines forward()
ToyTransformerModelModelOne concrete architecture
LayerModelAbstract; defines one computation step
DenseLayerModelOne concrete layer implementation
TokenizerI/OText ↔ token Tensor, both directions
InferenceEngineModelStateless — runs a Tensor through a given model's layers
TensorDataNumeric buffer + shape, with add / matmul
OutputGeneratorI/OFinal Tensor → text via Tokenizer::decode, then prints
